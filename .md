# Design Improvements Checklist

This document tracks the layout and design changes to achieve a premium, minimal, and elegant look for the wedding invitation.

## Core Visual Changes

- [x] **1. Simplify the color palette to 3 core tones**
  * Use warm ivory, deep charcoal, and muted gold only.
  * Remove multi-color gradients across sections and headings.
  * *Files to modify:* `Hero.tsx`, `EventDetails.tsx`, `Footer.tsx`, `Index.tsx`

- [x] **2. Replace decorative effects with calm surfaces**
  * Remove floating hearts, pulsing circles, sparkles, and bounce animations.
  * Keep only one subtle fade-in per section.
  * *Files to modify:* `Hero.tsx`, `Footer.tsx`, `EventDetails.tsx`

- [x] **3. Upgrade typography hierarchy**
  * Use one elegant serif for titles and one clean sans for body.
  * Example pair: Cormorant Garamond (titles) + Manrope (body).
  * Increase whitespace around headings; reduce excessive font-weight.
  * *Files to modify:* `index.html`, `Hero.tsx`, `Footer.tsx`

- [x] **4. Tone down glassmorphism**
  * Current blur + heavy shadows feel busy.
  * Use flatter panels: soft ivory background, hairline border, very light shadow.
  * *Files to modify:* `EventDetails.tsx`, `OurStory.tsx`

- [x] **5. Make one strong hero statement**
  * Keep couple names, date, and one short line only.
  * Reduce countdown visual prominence or hide it for a classic invitation style.
  * *Files to modify:* `Hero.tsx`

- [x] **6. Improve spacing rhythm**
  * Use a consistent section rhythm like 96px top and bottom padding.
  * Limit content width to increase elegance and readability.
  * *Files to modify:* `OurStory.tsx`, `EventDetails.tsx`, `Footer.tsx`

## Navigation & Language

- [x] **7. Simplify navigation**
  * Keep compact nav with text links only and subtle underline hover.
  * Reduce icon animation and logo emphasis.
  * *Files to modify:* `Navigation.tsx`

- [x] **8. Rewrite copy to shorter, premium language**
  * Use concise lines and avoid long poetic blocks.
  * This instantly feels more upscale and intentional.
  * *Files to modify:* `Hero.tsx`, `Footer.tsx`, `EventDetails.tsx`
